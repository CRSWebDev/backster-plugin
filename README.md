# Backster

> **Deprecated.** This plugin is no longer maintained and is no longer required by FrameworC (dropped from `crs-company/frameworc-theme` as of v1.11.1). Do not add it to new projects.

Backup solution for OctoberCMS (database + project files, daily/weekly rotation).

Existing installs can remove it once they no longer need it:

```bash
php artisan plugin:remove CRSCompany.Backster
```
